# Roadmap del Proyecto

Este roadmap resume el avance recomendado para construir la primera version de TallerGo.

## Fase 1. Analisis y diseno

Estado: completado como avance documental.

Entregables:

- Definicion del problema.
- Alcance de la primera version.
- Modulos principales.
- Requerimientos funcionales y no funcionales.
- Arquitectura del sistema.
- Modelo de datos inicial.

## Fase 2. Prototipo de interfaz

Estado: avance inicial.

Entregables:

- Pantalla de dashboard.
- Vista resumida de ordenes de trabajo.
- Indicadores de clientes, ordenes, ingresos e inventario.
- Navegacion visual de modulos.

## Fase 3. Base de datos

Estado: pendiente de implementar en Supabase.

Entregables:

- Crear proyecto en Supabase.
- Ejecutar script `docs/modelo-datos.sql`.
- Validar relaciones principales.
- Definir politicas RLS por rol.

## Fase 4. Funcionalidad inicial

Estado: pendiente.

Entregables:

- Login.
- Registro de clientes.
- Registro de vehiculos.
- Creacion de ordenes de trabajo.
- Consulta y cambio de estado de ordenes.

## Fase 5. Modulos administrativos

Estado: pendiente.

Entregables:

- Inventario de repuestos.
- Registro de pagos.
- Reportes operativos.
- Pruebas funcionales.

## Prioridad recomendada

1. Base de datos y autenticacion.
2. Clientes y vehiculos.
3. Ordenes de trabajo.
4. Inventario.
5. Pagos y reportes.
